## No cookies on Parole de RH

The Parole de RH website sets no cookies and uses no other tracker on visitors' devices. This is why no consent banner is displayed.

According to the CNIL, which presents the applicable rules on its page [Cookies et traceurs : que dit la loi ?](https://www.cnil.fr/fr/cookies-et-autres-traceurs/regles/cookies/que-dit-la-loi), setting certain trackers requires the user's prior consent. Parole de RH uses none.

## What this means in practice

| Item | Situation on Parole de RH |
|---|---|
| Audience measurement | No tool installed |
| Advertising | None |
| Social media buttons | None |
| Embedded videos, maps or content | None |
| Fonts | Hosted on the site itself |
| Images | Hosted on the site itself |
| Internal search engine | Runs in the browser, without cookies |

## Sites that links point to

A link to an external site (official source, software vendor) leads to a site that applies its own cookie rules.

## If this changes

If a service that sets cookies were added, this page would be updated and visitors' consent would be requested where the regulations require it. For any question: [contact@parole-de-rh.fr](mailto:contact@parole-de-rh.fr).

Other information about personal data is given in the [privacy policy]({{< relref "privacy-policy.md" >}}).
